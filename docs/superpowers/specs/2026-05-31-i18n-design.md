# Spec: Internacionalización (ES / EN)

**Fecha:** 2026-05-31
**Estado:** Aprobado

## Objetivo

Permitir que la app funcione en español e inglés. El idioma se detecta automáticamente del navegador (`navigator.language`) y el usuario puede cambiarlo con un botón `ES`/`EN` en el header. La preferencia persiste en `localStorage`.

## Enfoque

Translations object en `popup.js` — patrón idéntico al tema oscuro. Sin archivos externos, sin Chrome i18n API.

## Estado y detección

```js
let lang = localStorage.getItem('todo_lang') ||
           (navigator.language?.startsWith('es') ? 'es' : 'en');
```

- `localStorage.getItem('todo_lang')` — override manual (null si no hay preferencia guardada)
- `navigator.language?.startsWith('es')` — auto-detect: español si el navegador es es-*, inglés en cualquier otro caso

## Botón de idioma

### HTML en popup.html y tab.html

En el header, junto al botón de tema:

```html
<button class="icon-btn" id="lang-btn"></button>
```

**popup.html**: junto a `#expand` y `#theme`:
```html
<div style="display:flex;gap:6px;">
  <button class="icon-btn" id="expand" title="Abrir en pestaña"></button>
  <button class="icon-btn" id="lang-btn"></button>
  <button class="icon-btn" id="theme" title="Cambiar tema"></button>
</div>
```

**tab.html**: junto a `#theme`:
```html
<div style="display:flex;gap:6px;">
  <button class="icon-btn" id="lang-btn"></button>
  <button class="icon-btn" id="theme" title="Cambiar tema"></button>
</div>
```

El botón muestra texto `EN` o `ES` (el idioma al que cambiará), usando `font-size:10px; font-weight:600; letter-spacing:.04em` inline o con clase `.icon-btn` existente.

### Funciones en popup.js

```js
function syncLangBtn() {
  const btn = $('lang-btn');
  if (!btn) return;
  btn.textContent = lang === 'es' ? 'EN' : 'ES';
  btn.title = STRINGS[lang].langTitle;
}

function toggleLang() {
  lang = lang === 'es' ? 'en' : 'es';
  localStorage.setItem('todo_lang', lang);
  applyStaticStrings();
  syncLangBtn();
  render();
}
```

### `applyStaticStrings()` — actualiza el DOM estático

```js
function applyStaticStrings() {
  const S = STRINGS[lang];
  const h1 = document.querySelector('h1');
  if (h1) h1.textContent = S.appTitle;
  const draft = $('draft');
  if (draft) draft.placeholder = S.addPlaceholder;
  const cam = $('cam');
  if (cam) cam.title = S.camTitle;
  const urlBtn = $('url-btn');
  if (urlBtn) urlBtn.title = S.urlTitle;
  const expandBtn = $('expand');
  if (expandBtn) expandBtn.title = S.expandTitle;
  const themeBtn = $('theme');
  if (themeBtn) themeBtn.title = S.themeTitle;
}
```

Se llama en `init()` y en `toggleLang()`.

## Uso de STRINGS en popup.js

`DOW` y `MON` dejan de ser constantes globales — se accede a ellas vía `STRINGS[lang].days` y `STRINGS[lang].months`.

`PRIORITIES` y `CATS` se mantienen como constantes globales pero sus `label` se reemplazan con referencias a `STRINGS[lang]`. Patrón recomendado: recalcular con `const S = STRINGS[lang]` al inicio de las funciones que los usan.

### Funciones afectadas

| Función | Cambio |
|---|---|
| `fmtDue()` | Usa `S.today`, `S.tomorrow`, `S.yesterday`, `S.days[d]`, `S.months[m]` |
| `fmtCreated()` | Usa `S.months[d.getMonth()]` |
| `render()` | Usa `S.allDone`, `S.pending(n)`, `S.completed`, `S.emptyTitle`, `S.emptyHint` |
| `composeHTML()` | Usa `S.composePlaceholder`, `S.composeSave`, `S.composeCancel` |
| `saveCompose()` | Usa `S.screenshotName` como fallback de nombre |
| renderizado de PRIORITIES | Usa `S.priorities[t.priority]` para el label |
| renderizado de CATS/tabs | Usa `S.cats[cat.id]` para el label |
| `init()` | Llama a `applyStaticStrings()` y `syncLangBtn()` |

## Archivos modificados

| Archivo | Cambio |
|---|---|
| `starter/popup.js` | `STRINGS` object, `lang` state, `syncLangBtn()`, `toggleLang()`, `applyStaticStrings()`, todas las funciones con strings hardcodeados |
| `starter/popup.html` | `#lang-btn` en header |
| `starter/tab.html` | `#lang-btn` en header |

Sin cambios a `manifest.json`.

## Backward compatibility

Las tareas guardadas usan IDs estables (`cat: 'trabajo'`, `priority: 'alta'`) — no hay migración. Al cambiar idioma se re-renderiza todo y los labels aparecen en el nuevo idioma.

## Lo que NO incluye este spec

- Más de 2 idiomas (no pedido)
- Traducción del contenido de las tareas (texto libre del usuario)
- Cambiar el idioma del sistema Chrome (`chrome.i18n`)
