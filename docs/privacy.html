Privacy Policy

Last updated: May 31, 2026

Summary: Tareas stores your tasks locally on your device. No personal data is collected, sent to, or stored on any external server.

What data Tareas stores

Tareas stores the following data exclusively on your device, using Chrome's local storage APIs:

  • Task content (text, priority, category, due date)
  • Screenshots attached to tasks (as Base64 image data)
  • URLs and page titles saved with tasks
  • App preferences (theme: light/dark, language: ES/EN)

This data never leaves your device and is never transmitted to any server.

External network requests

When you save a task that includes a URL from a webpage, Tareas loads a favicon (small website icon) from Google's public Favicon API:

  • https://www.google.com/s2/favicons
  • https://t0.gstatic.com/faviconV2

This means the domain name of any URL you save may be sent to Google's servers as part of loading the favicon image. No other data is included in this request. This is the only external network request Tareas makes.

If you prefer not to send any data to Google, you can save tasks without including URLs.

Permissions

Tareas requests the following browser permissions:

  • storage — to save your tasks locally on your device
  • activeTab — to capture a screenshot of the current tab and read its URL and title when you explicitly click the camera or link button

These permissions are only exercised when you take an explicit action within the extension.

Data sharing

Tareas does not share, sell, or transmit your data to any third party other than the Google favicon requests described above.

Data deletion

You can delete all data stored by Tareas at any time by:

  • Removing the extension from Chrome (this deletes all local storage)
  • Clearing Chrome's extension storage via chrome://settings/siteData

Children's privacy

Tareas does not knowingly collect any information from children under 13.

Contact

Política de Privacidad

Última actualización: 31 de mayo de 2026

Resumen: Tareas guarda tus tareas localmente en tu dispositivo. No se recopilan, envían ni almacenan datos personales en ningún servidor externo.

Qué datos almacena Tareas

Tareas almacena los siguientes datos exclusivamente en tu dispositivo, usando las APIs de almacenamiento local de Chrome:

  • Contenido de las tareas (texto, prioridad, categoría, fecha límite)
  • Capturas de pantalla adjuntas a tareas (como imágenes Base64)
  • URLs y títulos de páginas guardados con tareas
  • Preferencias de la app (tema: claro/oscuro, idioma: ES/EN)

Estos datos nunca salen de tu dispositivo y nunca se transmiten a ningún servidor.

Peticiones de red externas

Cuando guardas una tarea que incluye una URL, Tareas carga un favicon (ícono del sitio web) desde la API pública de favicons de Google:

  • https://www.google.com/s2/favicons
  • https://t0.gstatic.com/faviconV2

Esto significa que el nombre de dominio de cualquier URL que guardes puede enviarse a los servidores de Google como parte de la carga del ícono. No se incluye ningún otro dato en esta solicitud. Esta es la única petición de red externa que realiza Tareas.

Si prefieres no enviar datos a Google, puedes guardar tareas sin incluir URLs.

Permisos

Tareas solicita los siguientes permisos del navegador:

  • storage — para guardar tus tareas localmente en tu dispositivo
  • activeTab — para capturar una captura de pantalla de la pestaña actual y leer su URL y título cuando haces clic en el botón de cámara o de enlace

Estos permisos solo se usan cuando realizas una acción explícita dentro de la extensión.

Compartición de datos

Tareas no comparte, vende ni transmite tus datos a ningún tercero, excepto las solicitudes de favicon de Google descritas anteriormente.

Eliminación de datos

Puedes eliminar todos los datos almacenados por Tareas en cualquier momento:

  • Eliminando la extensión de Chrome (esto borra todo el almacenamiento local)
  • Limpiando el almacenamiento de la extensión en chrome://settings/siteData

Privacidad de menores

Tareas no recopila deliberadamente información de menores de 13 años.

Contacto

Para preguntas sobre esta política de privacidad, escribe a: flavioisay@gmail.com
