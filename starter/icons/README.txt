Coloca aquí 4 íconos PNG de la extensión:

  16.png   (16×16)   — barra de herramientas
  32.png   (32×32)   — barra / Windows
  48.png   (48×48)   — página de extensiones
  128.png  (128×128) — Chrome Web Store / instalación

Sugerencia de diseño (coherente con la app):
  - Fondo: cuadrado redondeado en color de acento grafito (#1c1c1a).
  - Símbolo: un check (✓) blanco centrado, trazo grueso redondeado.
  - Deja ~18% de margen alrededor del símbolo.

Mientras no existan estos archivos, Chrome mostrará un ícono gris por defecto
(la extensión igual carga y funciona).
